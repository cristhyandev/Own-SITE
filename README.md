## 📌 Sobre o Projeto

Este repositório contém a página inicial (Landing Page) temporária criada para validar a configuração de domínio próprio, publicação via **GitHub Pages** e futura integração de e-mail profissional.

O objetivo principal deste projeto é estabelecer uma presença digital oficial e servir como ponto de partida para o meu portfólio de desenvolvimento.

---

## 🚀 Tecnologias Utilizadas

* **HTML5** — Estruturação do conteúdo da página.
* **CSS3** — Estilização e layout responsivo.
* **GitHub Pages** — Hospedagem contínua e gratuita do site.

---

## 🔧 Como visualizar o site

Assim que as configurações de DNS e GitHub Pages forem finalizadas, o site poderá ser acessado diretamente através do domínio personalizado ou do endereço padrão do GitHub Pages.
